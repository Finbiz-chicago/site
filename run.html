Executer

Le systeme demarre depuis un clone vide. Ce qui manque, vous l'apportez, et c'est dit avant que vous lanciez quoi que ce soit.

Ce qu'il faut avoir

Dockeravec le plugin Compose.
Disqueenviron 3 Go, dont la base de connaissances.
Vos propres clesLe scraper appelle un modele de langage pour l'etape d'extraction. Aucune cle n'est fournie : vous utilisez votre compte. Sans cle, tout le reste demarre et seule l'extraction est indisponible.

Demarrer

git clone https://github.com/finbiz/stack.git
cd stack
cp .env.example .env        # remplissez les valeurs, aucune n'est pre-remplie
./bootstrap.sh              # telecharge les donnees, restaure, demarre

La pile s'ecoute sur des ports locaux. Elle ne suppose ni proxy inverse, ni nom de domaine, ni certificat : elle fonctionne sur une machine nue.

Verifier que ca marche

./smoke-test.sh

Le test interroge reellement la base et le service de conversation. Il echoue si une variable manque ou si les donnees n'ont pas ete restaurees : un test qui ne sait pas dire non ne dit rien quand il dit oui.

Ce qui ne demarre pas depuis un clone

L'entree des donnees dans l'annuaire partenaire se pilote depuis un navigateur ou une personne s'est connectee elle-meme. C'est volontaire : aucun identifiant d'annuaire n'existe cote serveur, et aucun programme n'en detient.
